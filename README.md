## Publish it on GitHub Pages (about 10 minutes)

1. **Create a GitHub account** at github.com if you don't have one.
2. **Create a new repository.** Click **New**, name it (for example `portfolio`), set it to **Public**, and create it.
3. **Upload these files.** Either:
   - On the repo page, click **Add file → Upload files**, drag in everything from this folder, and commit, or
   - Use Git on your computer:
     ```bash
     git init
     git add .
     git commit -m "Add portfolio"
     git branch -M main
     git remote add origin https://github.com/YOUR-USERNAME/YOUR-REPO.git
     git push -u origin main
     ```
4. **Turn on Pages.** In the repo, go to **Settings → Pages**. Under **Build and deployment**, set **Source** to **Deploy from a branch**, choose **main** and **/ (root)**, and save.
5. **Wait a minute or two**, then open `https://YOUR-USERNAME.github.io/YOUR-REPO/`.
6. **Add the link** to your LinkedIn profile (Contact info and Featured section) and your resume.

Tip: if you name the repo exactly `YOUR-USERNAME.github.io`, your site lives at `https://YOUR-USERNAME.github.io/` with no repo name in the URL.
